Applied machine learning projects completed during the Udacity AI Programming with Python and Intro to Machine Learning Nanodegrees:

- [Flower species image classifier](https://github.com/erfan-taatizadeh/udacity-flower-image-classifier): a PyTorch deep neural network with a command-line train and predict app (102 classes)
- [Dog breed image classifier](https://github.com/erfan-taatizadeh/udacity-dog-breed-image-classifier): transfer learning with VGG, AlexNet, and ResNet
- [CIFAR-10 image classifier](https://github.com/erfan-taatizadeh/udacity-cifar10-image-classifier): a convolutional neural network in PyTorch
- [Finding donors (CharityML)](https://github.com/erfan-taatizadeh/udacity-finding-donors-charityml): supervised learning on U.S. census data
- [Customer segmentation (Arvato)](https://github.com/erfan-taatizadeh/udacity-identify-customer-segments): PCA and K-Means on German demographic data
